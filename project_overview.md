Simple-Calculator
Overview: A web-based Calculator app using HTML, CSS, and JavaScript. It performs basic arithmetic (add, subtract, multiply, divide) with a user-friendly interface.

Features:

Calculator UI: A keypad with buttons 0–9, operations (+, −, ×, ÷), a display screen, and a clear button.
Interactive Input: Users click buttons to build an expression; the display updates accordingly.
Calculation Logic: JavaScript evaluates the expression when “=” is pressed and shows the result. It handles operator precedence left-to-right (no advanced parsing).
Clear/Reset: The “C” button clears the current input.
Design: CSS styles the calculator with a grid layout and highlights buttons on hover or click.
Setup Instructions:

Clone: Place files in any folder.
Run: Open index.html in a browser (no server needed).
Use: Click on numbers and operators to form calculations. Press “=” to compute.
Usage: Works like a standard calculator. E.g., click 2, +, 3, = to get 5.
