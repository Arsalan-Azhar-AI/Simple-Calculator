
# Simple-Calculator

**Overview:**
A web-based **Calculator** built with **HTML**, **CSS**, and **JavaScript**. It performs basic arithmetic operations—addition, subtraction, multiplication, and division—through an intuitive user interface. This project is perfect for learning DOM manipulation, event handling, and front-end scripting logic.

---

## Features

* **Interactive Calculator UI:** Buttons for numbers (0–9), operations (`+`, `−`, `×`, `÷`), equals (`=`), and clear (`C`).
* **Dynamic Input Display:** Updates in real-time as users press buttons.
* **Calculation Logic:** Evaluates arithmetic expressions using JavaScript.
* **Reset/Clear Function:** Clears current input to start a new calculation.
* **Responsive Design:** CSS grid layout with hover and click effects for an enhanced UI experience.

---

## Setup Instructions

1. **Clone the Repository:**

```bash
git clone https://github.com/Arsalan-Azhar-AI/Simple-Calculator.git
```

2. **Run:**

   * Open `index.html` in your browser.
3. **Use:**

   * Click numbers and operators to build expressions.
   * Press `=` to compute results.
   * Press `C` to reset the display.
